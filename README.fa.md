# اتاق ماینر میکو — نسخه‌ی اصلاح‌شده

این بسته شامل مینی‌اپ (`index.html`) و بک‌اند Flask (`app.py`) است. فایل‌ها باید در یک پوشه باشند.

## راه‌اندازی محلی

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# Linux/macOS:
source .venv/bin/activate
pip install -r requirements.txt
```

متغیرهای محیطی را تنظیم کنید و سپس اجرا کنید:

```bash
python app.py
```

برای محیط تولید از این فرمان استفاده کنید:

```bash
gunicorn app:app
```

## متغیرهای محیطی

ضروری:

- `BOT_TOKEN`: توکن ربات تلگرام.
- `BASE_URL`: آدرس عمومی HTTPS مینی‌اپ، مانند `https://your-service.onrender.com`.
- `MONGO_URI`: رشته اتصال MongoDB. برای نگهداری دائمی اطلاعات، حتماً یک دیتابیس پایدار تنظیم کنید.

اختیاری:

- `ADMIN_ID`: آیدی عددی تلگرام ادمین؛ برای پنل ادمین و مدیریت برداشت‌ها.
- `BOT_USERNAME`: نام کاربری ربات، بدون `@`؛ اگر تنظیم نشود از تلگرام دریافت می‌شود.
- `SECRET_KEY`: کلید مشتق‌سازی امضای webhook؛ در غیر این صورت از `BOT_TOKEN` استفاده می‌شود.
- `STAR_USD`: ارزش دلاری هر Star؛ پیش‌فرض `0.013`.
- `TON_ADDRESS`: آدرس دریافت TON؛ تا وقتی تنظیم نشده، اسکن واریز TON غیرفعال است.
- `TONCENTER_KEY`: کلید اختیاری Toncenter.
- `SWAP_FEE`: کارمزد تبدیل؛ پیش‌فرض `0.02` (۲٪).
- `CASHOUT_FEE`: کارمزد انتقال ارز استخراج‌شده به کیف پول؛ پیش‌فرض `0`.
- `CASHOUT_MIN_USD`: حداقل دلاری انتقال ارز ماین‌شده؛ پیش‌فرض `0.01`.
- `CASHOUT_DAILY_USD`: سقف روزانه انتقال ارز ماین‌شده به ازای هر کاربر؛ پیش‌فرض `25`.
- `MIN_WD_TON`, `MIN_WD_USDT`: حداقل‌های قابل تنظیم برداشت؛ حداقل برداشت نهایی طبق منطق برنامه ارزش دلاری ۱۰ دلار را هم بررسی می‌کند.
- `MAX_WORTH_RATE`, `BUCKET_CAP`: محدودیت رشد ارزش بازی؛ پیش‌فرض به‌ترتیب `0.0003` دلار در ثانیه و `6` دلار.
- `MONGO_URI` خالی: فقط برای توسعه‌ی موقت، از دیتابیس حافظه‌ای استفاده می‌شود و داده‌ها با ری‌استارت از بین می‌روند.

## نکات مهم قبل از انتشار

1. در Render یا هر میزبان دیگر، `BOT_TOKEN`، `BASE_URL` و `MONGO_URI` را در بخش Environment تنظیم کنید. از ذخیره کردن توکن در فایل یا Git خودداری کنید.
2. بدون MongoDB پایدار، موجودی‌ها، کیف پول‌ها و تاریخچه‌ی تراکنش‌ها برای استفاده‌ی واقعی قابل اتکا نیستند.
3. قابلیت‌های واریز/برداشت/انتقال به دارایی واقعی را ابتدا در محیط آزمایشی بررسی کنید. مدیریت موجودی بهتر شده و webhookهای تکراری برای Stars و TON با شناسه‌ی یکتا کنترل می‌شوند؛ بااین‌حال، این نسخه جایگزین بازبینی مستقل امنیت مالی، مانیتورینگ و فرآیند تطبیق تراکنش‌ها نیست.
4. منطق بخش عمده‌ای از پیشرفت بازی هنوز در سمت مینی‌اپ اجرا می‌شود. اعتبارسنجی ساختار و محدودیت رشد سمت سرور جلوی بعضی دستکاری‌های ساده را می‌گیرد، اما ضدتقلب کامل نیازمند انتقال رویدادهای اقتصادی و پیشرفت بازی به منطق authoritative سمت سرور است.
5. بعد از اعمال متغیرها، `/health` را بررسی کنید؛ پاسخ سالم باید `ok` باشد. ربات برای ورود به بازی به `BASE_URL` عمومی و قابل دسترس با HTTPS نیاز دارد.

## اصلاحات شاخص

- رفع خطای ۵۰۰ رده‌بندی هفتگی به‌علت متغیر زمان تعریف‌نشده.
- جلوگیری از اعتماد بک‌اند به مقدار `worth` ارسالی مرورگر و محاسبه‌ی ارزش از وضعیت پاک‌سازی‌شده.
- جلوگیری از دستکاری فیلد مالی «مجموع انتقال‌شده به کیف پول» از سمت مرورگر.
- کنترل تکرار webhookهای پرداخت Stars و واریز TON با شناسه‌های پردازش‌شده.
- rollback بهترین‌تلاش در مسیرهای کیف پول هنگام شکست ثبت دفتر تراکنش.
- جلوگیری از حذف آپدیت‌های معلق تلگرام هنگام تنظیم webhook و انتقال راه‌اندازی ربات به thread پس‌زمینه.
- timeout برای درخواست‌های کیف پول و پنل ادمین در رابط کاربری.
- بهبود نمایش روی موبایل با viewport پویا، حلقه‌ی افکت مقاوم‌تر و دسترسی بهتر با صفحه‌کلید.
- حذف محدودیت بزرگ‌نمایی اجباری موبایل و مقاوم‌سازی خواندن تنظیم صدا در صورت خطای `localStorage`.
